# InVitGeneBot - Telegram Invoice Generator

A production-ready Telegram Bot written in **Python 3.12** using **python-telegram-bot (v21+)** and **ReportLab** designed to construct, record, edit, and instantly deliver high-quality PDF business invoices on demand.

## 🚀 Key Features

* **Instant Invoice Creation**: Guided conversation flow for adding line items, pricing, and buyer information.
* **ReportLab Integration**: Native PDF generation with styled document layout and clean typography.
* **SQLite Storage**: Powered by SQLAlchemy async engine for user profiles and historical record management.
* **Render Ready**: Configured out of the box with `render.yaml` for zero-overhead worker deployments.
